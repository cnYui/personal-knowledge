# Chat 页面一键清空聊天记录

日期：2026-04-29

## 背景

当前 `chat` 页面已经支持对话发送、流式输出和本地历史持久化，但缺少显式的“清空全部聊天记录”入口。

用户如果想重置当前会话，只能手动清理浏览器存储或改代码，操作成本高，也容易误判为系统没有删除能力。

## 目标

- 在 `chat` 页面提供一键删除全部聊天内容的入口
- 删除前提供二次确认，避免误触
- 复用现有 `clearChatMessages` 和 `useClearChatMessages`，不新增第二套清理逻辑

## 非目标

- 这次不引入后端会话删除接口
- 这次不做按单条消息删除
- 这次不改聊天消息存储结构

## 设计决策

### 操作入口

把“清空对话”放在 `KnowledgeChatPage` 顶部操作区，和消息列表、输入框形成清晰分层，避免把危险操作塞进输入区域附近导致误触。

### 确认方式

复用项目已有 `ConfirmDialog` 模式，而不是直接使用 `window.confirm`。

原因：

- 现有记忆删除流程已经使用统一确认弹窗
- 风格一致，后续维护更集中
- 便于测试“取消不删除、确认后删除”的分支

### 状态收敛

清空动作直接调用 `useClearChatMessages`，成功后通过 React Query 把 `chat-messages` 收敛为空数组。

这样可以保证：

- 页面立即刷新为空状态
- 本地 `localStorage` 同步清空
- 不需要在页面层额外操作存储

## 风险与取舍

- 如果在流式回复进行中仍允许清空，可能出现“刚清空后又被新流片段补回”的竞争。
- 这次优先采用最小可行方案：当发送中或清空中时禁用清空按钮，先阻断最明显的竞态入口。
- 更细粒度的“中断流再清空”不在这次范围内。
